# ADR 0001 — Nuxt 4 instead of Nuxt 3

**Status:** accepted 2026-10-30 (plan decision D1)

Nuxt 3 reached end of life on 31 July 2026 and no longer receives security patches. Nuxt 4 keeps the agreed stack (Vue 3, TypeScript, Tailwind, Pinia) and uses the `app/` source directory.

Pinned toolchain notes:
- TypeScript is held at 5.9: TypeScript 7 (native) is not loadable by `vue-tsc`, and `openapi-typescript` requires 5.x.
- `esbuild@0.28` is a direct dependency so npm doesn't hoist the 0.25 copy that `@nuxtjs/i18n` bundles, which conflicts with Vite 8.
